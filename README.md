# Student-Academic-Performance-Tracker
Created by: Miranda Acon and Natalia De Prisco
Project Overview
This project is a Python application designed to help students track their academic performance. Users can add courses, record assignment grades, track study hours, and analyze their results using Pandas.
Features
    •    Add and remove courses


    •    Record assignments and calculate grades


    •    Track study hours and study sessions


    •    View academic standing


    •    Generate Pandas reports and graphs


Python Concepts Used
Functions, loops, conditionals, dictionaries, lists, object-oriented programming, exception handling, and Pandas.
How to Run
    1    Open the project notebook in Google Colab.


    2    Run all code cells.


    3    Use the interactive menu to select an option from 1–12.


    4    Enter your courses, grades, and study hours to generate reports.
